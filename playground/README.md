# MES 交互配置实验室

一个独立运行的 Vue 3 + TypeScript + Element Plus 前端练习站，用作后续 UI 自动化的被测系统。提供五个分类页及一个全部组件页；只实现前端及其交互，没有建立自动化框架，也没有连接真实 MES、数据库或 Redis。

## 启动

需要 Node.js 20.19+ 或 22.12+，建议 Node.js 22 LTS。

```bash
cd playground
npm ci
npm run dev
```

访问 http://127.0.0.1:5173/ 。端口被占用会明确退出，不悄悄换端口。可临时使用 `npm run dev -- --port 5174`。默认仅本机访问；需要局域网演示时可明确指定 `--host 0.0.0.0`。

```bash
npm run typecheck
npm run build
npm run preview
```

生产构建输出到 dist/；预览地址为 http://127.0.0.1:4173/ 。静态部署使用 hash 路由，服务器不需要为各页面配置回退路径。

## 页面与规则

| 页面 | 地址 | 交互内容 |
|---|---|---|
| 基础输入 | /#/inputs | 必填名称、任意格式自由文本、非负整数、三位小数、100 字符备注、只读与禁用对照 |
| 联动规则 | /#/linkage | A/B 双向互斥，C 自动勾选锁定 D，单选启用文本框，开关启用必填原因 |
| 嵌套弹框 | /#/dialogs | 外层控件配置、内层变量搜索与分页选择、逐层确认和取消、显示配置标签页 |
| 扩展输入 | /#/extended | 下拉单选、下拉方框勾选多选、车间产线级联、日期范围、时间、日期时间一体输入、颜色、开关/滑块、文件选择 |
| 动态表格 | /#/table | 增删行、行内输入、启用开关、重复编码校验、搜索和分页 |
| 全部组件 | /#/all | 同一页集中展示上述五组完整控件，提供区域快速定位、返回顶部及分区保存 |

“全部组件”页与分类页复用同一组控件实例和草稿：例如在基础输入页填写后进入全部组件页，输入内容继续保留。每个区域使用原有保存和恢复按钮，互不代替；刷新仍只恢复已保存数据，不增加第二套存储记录。重置同时作用于全部组件页和分类页。

### 已确认的联动行为

- 选中 A 时 B 未选中且禁用；取消 A 后 B 恢复。B → A 对称。
- 选中 C 时自动勾选 D，D 禁用且不能取消。取消 C 后 D 保持勾选并恢复可编辑。
- 手动单选模式下文本框可输入且必填；系统模式下禁用，生效值为“系统标准值”。切换模式保留手动草稿。
- 高级配置关闭时原因框禁用，开启时必填。

### 输入示例的确定边界

- 下拉单选：处理优先级只保留一项，新选择替换旧值。
- 下拉勾选多选：功能标签支持称重、复核、记录、签名；点击方框或文字切换选中，选中后保持展开，可连续勾选。支持搜索、已选数量、逐个移除及清空；搜索过滤不会清除已选项。保存后刷新恢复。
- 整数数量：0–9999，只接受 ASCII 数字 0–9。
- 小数重量/弹框固定值：0–100000，最多 3 位小数；不接受负数、指数或字母。允许编辑中的空值/小数点，保存时要求完整数字。
- 非法数字输入保留最后合法编辑值并提示，不静默删去非法字符拼成其他值。
- 备注和弹框配置说明：最多 100 个 Unicode 码点；中文和英文各计 1，单码点表情计 1，复合表情可能占多个码点。支持中文输入法合成后处理。
- 颜色和日期为选择器值；告警阈值 0–100、步长 5，告警关闭时相关输入禁用。
- 计划执行时间：可选的日期时间一体输入框，支持直接输入和弹层选择年月日、时分秒，可清空。显示与保存格式为 `YYYY-MM-DD HH:mm:ss`，按本地时间字符串处理，不自动转换为 UTC；与原有日期区间、提醒时间分别保存。旧本地记录缺少该字段时自动补空值，原配置保留，直到显式保存才写回。
- 文件：TXT/CSV/JSON/PNG/JPG/JPEG，最多 2 MiB（页面简称 2 MB）。仅选择并记录元数据，**不上传文件内容**；刷新不能恢复文件对象。
- 表格：1–20 行，每页 5 行。编码、名称必填；编码按去除首尾空白、大小写不敏感判断重复。数量大于 0 且不超过 100000，3 位小数。单位 kg/g/件，彼此不换算、不汇总不同单位。

这些是练习站规则，不是实际 MES 的生产业务规格。

## 草稿、保存和重置

页面草稿与已保存快照分离。页面间切换保留当前标签页内的草稿；刷新恢复最后一次显式保存。恢复已保存按钮放弃本页面草稿。

弹框确认过程：

```text
内层选择变量 → 确认选择 → 只更新外层草稿
外层配置草稿 → 确认并保存 → 写入本地存储
任一层取消 / 关闭 / Escape → 丢弃该层修改
```

外层取消会连同已经内层确认的选择一起丢弃。遮罩点击不会关闭弹框；内层关闭不会同时关闭外层。切换页面会关闭该页面打开的配置弹框。

存储 key 为 `mes-interaction-lab:v1`，包含版本、五个模块的数据和各模块保存时间。右侧“已保存结果”来自保存快照，展开“查看配置数据”可观察实际数据。

仅写成功后反馈保存成功。损坏或不支持的存储记录显示警告、加载默认草稿，不在读取时覆盖原记录；显式保存或确认重置后才更新。存储被禁用/空间不足时显示中文失败信息，草稿保留。建议单标签页编辑同一组数据，不提供多标签并发合并。

“重置全部示例”需要确认，仅删除本站 key，并重建所有页面草稿，不清空其他浏览器存储。

## 后续自动化入口

- 页面入口：`nav-inputs`、`nav-linkage`、`nav-dialogs`、`nav-extended`、`nav-table`、`nav-all`。
- 全部组件页：`section-inputs` 等限定区域，`jump-inputs` 等快速定位按钮。原控件 test id 保持不变且在 DOM 中唯一；多个“恢复已保存”按钮应先限定区域。
- 输入：`config-name`、`free-text`、`integer-count`、`decimal-weight`、`limited-note`、`note-count`。
- 联动：`checkbox-a` 至 `checkbox-d`、`source-system`、`source-manual`、`manual-value`、`effective-value`。
- 弹框：`open-config-dialog`、`control-dialog`、`choose-variable`、`variable-dialog`、`variable-search`、`select-V-001` 等变量选项、`variable-confirm`、`variable-cancel`、`dialog-confirm`、`dialog-cancel`。
- 保存：`basic-save`、`linkage-save`、`extended-save`、`table-save`；结果：`basic-saved-result` 等。
- 表格：持久化行 ID 限定行和字段，例如 `material-row-row-001`、`row-code-row-001`，新增行的 ID 为 UUID，不按可见行号充当身份。
- 全站重置：`reset-all`。
- 下拉：`priority-select`、`feature-tags`、`feature-tags-count`；候选项如 `feature-option-称重`。多选使用 listbox/option 语义，方框显示来自同一选择状态，断言 option 的 `aria-selected` 及已选标签；不对装饰方框使用 `.check()`。键盘可聚焦“功能标签” combobox 后用方向键和 Enter 选择，Escape 收起。
- 日期时间：`planned-datetime` 或名称为“计划执行时间”的 combobox；弹层内按当前月份限定日期单元格，避免相邻月份同名日期；时间弹层和日期弹层各有“确定”，应限定对应层。

组件库选择器的 test id 可能位于外层容器；定位实际 input 时应限定容器或使用标签/角色。断言用真实 disabled、字段值、可见错误、已保存结果以及刷新结果，而不只检查消息提示。

## 代码职责

- `src/model.ts`：数据类型、默认值、输入规则、存储结构校验。
- `src/store.ts`：专用 key 的读写、已保存状态、错误反馈和全站重置。
- `src/views/`：五个业务练习页面；`src/components/`：数字输入和页面展示组件。
- `src/components/ComponentWorkspace.vue`：统一挂载并逐组缓存控件；分类页显示对应组，全部组件页显示五组，保持同一实例的草稿。
- `src/App.vue`：六页 hash 导航及全站重置生命周期；`src/style.css`：响应式布局与控件状态样式。

本地浏览器验收记录见 `VERIFICATION.md`。仅代表这个练习站的验证，不代表真实 MES 验收。

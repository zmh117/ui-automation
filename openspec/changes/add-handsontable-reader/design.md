## Context

EBR 的 HotTable 外层已有定位标识，单元格由 Handsontable Pro 6.2.6 生成；查看页可开启 renderAllRows，但任务切换仅加载部分数据并重算行号。通用扫描器已有 Frame/Shadow、可见性和关系模型。

## Goals / Non-Goals

**Goals:** 自动化侧提供独立读取 API、发现集成与 JSON 导出；按预算读取 DOM 显示内容、合并跨度、选定计算样式和嵌入控件状态，关联外层容器、表格、渲染行及单元格。

**Non-Goals:** 不修改前端、读取 Vue 私有实例、自动滚动/编辑/切换任务、推导后端原始值或预期业务结果；不承诺完整模板覆盖，不建立跨任务坐标身份。

## Decisions

- 保持读取器为自包含浏览器函数，通过现有定位与可见性工具获取表格根节点；发现协调器逐个调用，普通扫描排除 Handsontable 数据格以免重复与错误行列建模。
- 行列标题作为当前快照中的观察坐标，DOM 槽位只作为渲染位置。禁止把显示文本、重复标题或可变坐标当作稳定业务主键；没有已验证业务身份时关系节点仅限快照。
- 固定区域逐个记录 pane 来源；仅当标题唯一且跨度与内容/样式一致时合并为副本，冲突明确保留。合并只记录锚点与跨度，不生成不可见虚构单元格。
- 批量读取 DOM，样式仅固定白名单；细胞数、文本和内容子节点均有预算，未读、超限、未知总量明确记录。默认不读整片 HTML、图片 URL、密码内容。
- 专用 handsontable.json 保留 reportId 与 snapshotId；ui-model.json 增加容器包含关系。断言使用独立测试预期，业务值未知不自动从显示文本转换。

## Risks / Trade-offs

- [自定义或缺失标题无法恢复数据坐标] → 保留 rendered-position 和未知坐标，禁止跨快照合并。
- [滚动、隐藏、任务加载导致不完整] → coverage 固定为 rendered-dom 范围，总数未知；不宣称全部批记录覆盖。
- [DOM 与业务原始值不同] → rawValue 未知；后续有明确需要再引入受控公共读取接口。
- [真实部署样式或版本差异] → 固定公开的 6.2.3 组件浏览器验证，保留 EBR 声明的 6.2.6 差异，明确未做真实 MES 后端验收。

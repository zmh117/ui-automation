## Why

现有六页确认目录包含 2453 条测试，全量适合回归，但日常冒烟需要较小且可证明覆盖强度的用例集合。用户已确认接入微软 PICT，按组生成合法 n-way，补非法代表和边界，并复用执行与中文报告。

## What Changes

- 新增 PICT 冒烟模式，`--way N` 指定正整数强度，默认 2；每组实际强度为 N 与字段数的较小值。
- 合法组合由真实 PICT 引擎生成；保留每条违规规则的代表、现有有限样本/边界，并保留全部操作场景及分类页、全部组件两种入口。
- 导出选例清单、PICT 模型/原始输出、映射和覆盖核验结果，再交给现有 Playwright 执行。
- 中文报告区分冒烟完成与全量覆盖，保留已知分页失败，不改变业务断言。
- 提供项目内 PICT 安装脚本和已有二进制路径配置；原有全量命令行为保持兼容。

## Capabilities

### New Capabilities
- `pict-nway-smoke`: 可复核的组内 n-way 选例、负向样本补充及现有 UI 执行集成。

### Modified Capabilities
无。

## Impact

影响 automation 的选例模块、执行包装、配置用例注册、报告器与中文报告。读取既有参数化测试的完整计划作为模型来源，避免维护另一套业务规则。PICT 为本地原生可执行文件，固定源码版本并记录二进制指纹；无模型 API、数据库或 Redis 接入。

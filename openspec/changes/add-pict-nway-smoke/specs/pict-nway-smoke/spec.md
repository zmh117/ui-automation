## ADDED Requirements

### Requirement: PICT 组内合法 n-way
系统 SHALL 使用微软 PICT 为已确认有限候选组生成合法 n-way，默认 N=2，N 必须是正整数，每组实际强度为 min(N, 字段数)，并保存可复核原始证据。

#### Scenario: 二阶和三阶覆盖
- **WHEN** 对同一已确认目录分别请求 2-way 和 3-way
- **THEN** 每组独立覆盖所有可行二元组或三元组，字段不足时覆盖全部合法完整组合，输出所选候选的原始 ID 和值

#### Scenario: 特殊值与约束
- **WHEN** 候选值包含空串、中文、数组、对象、换行或逗号
- **THEN** 编码与解码保持值和类型不变，PICT 输出不得包含违反合法域约束的配置

### Requirement: 补充负向样本和操作场景
系统 SHALL 在合法 n-way 之外，补充每条违规规则代表和每个字段的全部已确认有限样本，并保留全部明确操作场景及其现有页面入口。

#### Scenario: 互斥及依赖非法目标
- **WHEN** A/B 同开、C 开 D 关被标记为非法候选
- **THEN** 冒烟仍包含对应规则的负向代表，继续通过正常 UI 验证禁用或联动，不绕过 UI 注入非法数据

#### Scenario: 全非法或单字段组
- **WHEN** 一个组没有合法候选，或仅有一个字段
- **THEN** 无合法组明确标记，负向补充保留有限样本；单字段组所有已确认样本均被保留

### Requirement: 执行前独立核验
系统 SHALL 核验所选合法行的 n 元组覆盖、负向规则及样本覆盖，核对执行模型指纹；失败时必须停止，不将未验证选择冒充成功冒烟。

#### Scenario: 缺失 PICT 或覆盖缺口
- **WHEN** 二进制不可用、PICT 失败/超时、返回非法或未知行、覆盖不完整
- **THEN** 命令以中文错误和非零退出码结束，不启动 UI 执行、不回退为任意抽样

#### Scenario: 执行模型漂移
- **WHEN** 执行时的候选定义与选例时不一致
- **THEN** 明确拒绝执行并要求重新生成冒烟清单

### Requirement: 执行与中文范围报告
系统 SHALL 提供只生成计划和执行冒烟两种入口，复用现有 Playwright 断言、截图、trace 和中文报告，区分选例覆盖与实际通过，不改变全量命令默认行为。

#### Scenario: 冒烟完整执行
- **WHEN** 所选冒烟全部执行结束
- **THEN** 报告显示 N、每组覆盖及通过/失败统计，smokeComplete 表示冒烟执行完整，coverageComplete 不标记全量完成，已知业务失败仍返回非零退出码

#### Scenario: 筛选或中断
- **WHEN** 冒烟附加 grep 筛选或执行中断
- **THEN** 报告标明范围或中断，不能宣称全部冒烟通过；中断清理本次测试进程

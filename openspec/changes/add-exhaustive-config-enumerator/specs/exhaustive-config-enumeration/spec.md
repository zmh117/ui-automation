## ADDED Requirements

### Requirement: 框架无关的有限模型

系统 SHALL 接受声明式 JSON 模型，包含模型标识、版本、字段有限候选值及约束；核心 MUST 不依赖 Vue、DOM 或 Node 内置模块，并在枚举前拒绝格式错误、空值域、重复标识或值、未知字段引用及非 JSON 数据。

#### Scenario: 不同项目复用
- **WHEN** 两个不同 Vue 项目提供各自的有效模型
- **THEN** 同一枚举 API SHALL 无需修改核心代码即可生成各自的候选配置

#### Scenario: 错误模型提前拒绝
- **WHEN** 约束引用不存在的字段或字段值域为空
- **THEN** 系统 MUST 报告包含模型位置的错误，且不得输出部分候选或创建成功报告

### Requirement: 全量保留合法与非法组合

系统 SHALL 按声明顺序枚举每个候选组合且不重复，不得因业务非法而剪枝；每条结果 MUST 包含完整取值、确定标识、合法性及全部违反的规则。

#### Scenario: A B C D 完整枚举
- **WHEN** 四个布尔字段应用 A 与 B 互斥、C 要求 D 的规则
- **THEN** 系统 SHALL 输出 16 条候选，9 条合法、7 条非法；A/B/C 为真且 D 为假的候选 MUST 同时包含两条违规规则

#### Scenario: 类型和复合值
- **WHEN** 候选包含数字、字符串、空值、数组或 JSON 对象
- **THEN** 系统 SHALL 保留类型，结构化比较不得把数字 1 与字符串 "1" 视为相等

### Requirement: 惰性枚举与完成性报告

系统 MUST 逐条生成且不缓存全部组合；总数及计数 MUST 精确；数量预算、取消或消费方提前停止时 SHALL 明确报告剩余数和未完成状态。

#### Scenario: 大空间有限消费
- **WHEN** 70 个布尔字段设置生成上限为 3 条
- **THEN** 系统 SHALL 报告总量 1180591620717411303424，输出 3 条且标记未完成，不先遍历整个空间

#### Scenario: 取消或提前停止
- **WHEN** 消费方取消或在完整枚举前结束迭代
- **THEN** 汇总 MUST 保留已生成数量且不得标记全量完成

#### Scenario: 输入输出隔离
- **WHEN** 调用方修改原始模型或此前生成结果中的数组或对象
- **THEN** 后续候选及规则分类 MUST 不受该修改影响

### Requirement: 可追踪导出

命令行 SHALL 导出模型快照、逐行候选及统计清单，清单 MUST 包含模型指纹与完成状态；不得覆盖已有输出目录，或将 I/O 失败声明为完整导出。

#### Scenario: 完整和预算导出
- **WHEN** 完整导出 A/B/C/D，或以 3 条预算导出同一模型
- **THEN** 前者 SHALL 报告 16 条且退出码 0；后者 SHALL 报告 3 条且退出码 2，标记未完成

### Requirement: 明确配置生成边界

文档与产物 MUST 区分配置分类和 UI 测试结果。非法配置 SHALL 作为后续正常 UI 拒绝或自动修正测试的候选，不得自动写入应用存储、调用业务接口或声称生成了执行路径。

#### Scenario: 非法候选不执行副作用
- **WHEN** 枚举出 A 和 B 同时为真的候选
- **THEN** 系统 SHALL 仅输出取值和违规原因，不改变练习站状态或任何业务数据

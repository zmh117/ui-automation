## Why

当前只有 Vue 练习站和自动化设计，缺少可复用的配置枚举实现。用户已要求先实现有限值域的全量枚举，保留非法组合用于正常 UI 拒绝或联动测试，并能接入其他 Vue 项目。

## What Changes

- 增加独立 TypeScript 包，通过 JSON 模型定义字段、有限候选值及声明式约束，无 Vue、DOM 或练习站运行时依赖。
- 流式枚举全部候选组合，分类为合法或非法，返回全部违规规则；不因业务非法而剪掉组合。
- 提供模型校验、确定顺序与用例标识、精确总量、数量预算及取消状态，区分完整与部分枚举。
- 提供命令行导出、A/B/C/D 与其他表单示例、独立算法验证及中文接入说明。
- PICT 保留为后续冒烟候选集生成工具，本轮不安装或实现；本轮不生成浏览器操作路径，不执行 UI 或绕过 UI 的数据测试。

## Capabilities

### New Capabilities
- `exhaustive-config-enumeration`: 与前端框架无关的有限配置全量枚举、违规分类、导出与完成性报告。

### Modified Capabilities

无。

## Impact

- 新增 `packages/config-enumerator/`，不修改练习站的业务行为或存储。
- 更新根目录入口说明与现有方案，反映全量保留非法组合的最新决策。
- 核心无运行时第三方依赖；构建使用 TypeScript，验证使用 Node 内置测试工具。交付证据仅涵盖算法与本地包接入，不代表真实 MES UI 验收。

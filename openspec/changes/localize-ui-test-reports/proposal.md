## Why

现有 Playwright 错误快照和英文断言需要技术人员解释，用户难以直接判断操作、预期、实际和影响。用户已确认新增中文报告、为已有运行补生成，并保留原始证据。

## What Changes

- 每次 UI 测试结束自动生成 `中文测试报告.md` 和 `中文失败报告.md`，按实际结果区分通过、失败、超时、中断、未执行和仅计划。
- 用稳定用例标识映射中文场景说明，结合原始断言解析预期与实际，链接截图、trace 和原始日志；未知错误明确提示人工排查，不编造根因。
- 提供已有运行的离线补生成命令，并补齐用户指定运行的中文报告。
- 保留现有 HTML、JSON、英文错误快照及测试断言；不修改页面行为。

## Capabilities

### New Capabilities
- `chinese-ui-test-reporting`: 依据本地执行证据自动生成可独立阅读的中文结果与失败报告。

### Modified Capabilities
无。

## Impact

影响 automation 报告器、命令入口、说明文档及新增报告单元测试；无需新依赖和外部服务。数据来源仅为本地测试产物，不涉及真实 MES 数据库、Redis 或设备。本次不修复已发现的分页问题，不改变覆盖范围。

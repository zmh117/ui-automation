## Why

用户要求开发脚本自动操作页面、执行断言并记录每条结果，范围已确认为本项目六个页面的全部组件。现有 discover 只提供待确认字段，现有枚举器只生成配置候选，尚无浏览器执行层。

## What Changes

- 补齐五类组件与全部组件页的有限值域、独立预期、保存回显与状态转换规格，由用户确认后执行。2026-10-07 已确认分组全量、有限样本和断言。
- 在确认后增加 Playwright Test 执行层，消费枚举候选，通过正常 UI 完成配置、保存、刷新和结果核对。
- 非法候选按输入拒绝、自动修正、禁用或保存校验分别验证，正确拦截视为通过；禁止通过应用存储写入、Vue 实例或强制点击构造非法状态。
- 覆盖二层弹框、单/多选、级联、日期时间、文件、表格、页面切换、分区保存与重置等实际组件。
- 记录逐用例输入、操作、断言、分类与执行状态，并提供 HTML 报告、JSON 结果、失败截图和 trace；支持可见窗口与调试减速。

## Capabilities

### New Capabilities

- `playground-ui-execution`: 六页组件的候选配置执行、独立断言、隔离和可审计报告。

### Modified Capabilities

无。页面发现继续保持只读及指定入口展开；通过独立执行命令执行本次明确授权的本地 UI 测试。

## Impact

- 计划新增独立 `automation/` 项目；复用 `packages/config-enumerator` 的枚举能力，保持核心无浏览器依赖。
- 被测系统为本地 Vue 练习站；实际 MES、接口、数据库、Redis 和设备不在本次执行范围。
- 测试预期不导入被测页面的校验函数；发现报告不能直接替代已确认的断言规格。
- 除实现所需且明确标明的定位适配外，不因测试失败自动修改被测业务规则。
- 详细覆盖规格见本变更 `coverage-review.md`；在确认组合粒度与样本之前不开始依赖这些选择的执行器编码及运行。

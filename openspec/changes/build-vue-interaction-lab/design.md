## Context

项目尚无应用工程。用户要求先建立 Vue 被测前端，已确认 A/B 双向互斥禁用、C 自动勾选锁定 D、取消 C 后保留 D，以及仅前端 localStorage 持久化。

## Goals / Non-Goals

**Goals:** 五个分类页及一个全部组件页提供基础输入、依赖联动、嵌套弹框、扩展输入和动态表格；明确草稿、确认和保存结果，支持刷新与重置，便于后续自动化定位。

**Non-Goals:** 不实现自动化执行器、真实 MES 业务或后端 API；文件只在浏览器选择，保存元数据并标明文件内容未上传。

## Decisions

- 独立 playground/ 工程：Vue 3、TypeScript、Vite、Element Plus；依赖固定版本，避免混入原页面资料目录。简单 hash 导航提供六个页面，重用通用面板和数字输入组件。
- ComponentWorkspace 对每组控件只缓存一个组件实例。分类路由只激活对应组，全部组件路由激活五组；使用逐组 KeepAlive 避免两份表单草稿和重复 DOM 标识。全部页分区保存，共享原有存储结构；重置销毁整个工作区重新初始化。切换路由显式关闭嵌套弹框。
- 页面草稿与已保存快照分离，显式保存才写 localStorage。存储写入成功后才反馈成功；解析或 schema 异常显示警告并使用默认状态，不静默覆盖旧值。
- 外层弹框克隆已保存配置；内层变量弹框克隆外层选择。内层确认只改外层草稿，外层确认才持久化。取消、关闭图标和 Escape 均丢弃当前层草稿，遮罩不误关闭。
- A/B 禁用由对方选中状态推导；D 的禁用由 C 推导，C 变为 true 时设置 D=true，不用双向 watcher 循环。单选为手动时才启用关联输入，切回系统保留草稿但使用系统值。
- 数字输入采用文本 input 与明确输入策略，不依赖 type=number 自动接受 e 等形式。提供非负整数、非负三位小数；自由文本不限格式，备注最多 100 个 Unicode 码点，中文输入合成后校验。
- 页面提供语义标签、真实 disabled、稳定 data-testid、校验错误、保存结果和局部规则说明。通过 Vue 模板安全显示用户文本。
- 扩展项包括单选/多选下拉、车间产线级联、日期区间、时间、滑块、开关、颜色、文件元数据；动态表格提供新增、删除确认、行校验、搜索和分页。
- 优先级为单选下拉；功能标签为带方框勾选样式的多选下拉。复用 Element Plus 的多选状态、搜索、标签移除与键盘交互，option 槽只增加视觉勾选标记，不嵌套第二套可交互 checkbox，以免一次点击触发两次切换。可访问状态仍由 option 的 aria-selected 表达，数据继续使用现有 tags 数组。
- 计划执行时间使用 datetime 选择器，支持输入和日历/时分秒弹层，保存本地墙上时间字符串 YYYY-MM-DD HH:mm:ss，不自动转 UTC；字段可空。读取旧 v1 记录时仅在内存补充缺失的 dateTime 空串，保留已有配置，不在读取时写回。非空值校验实际日历日期和时分秒范围。

数据流：页面输入 → 草稿 → 校验 → 写专用 localStorage key → 更新已保存快照 → 显示结果。各页面只保存本模块；全站重置先确认，仅删除本站 key 并重建所有页面草稿。

## Risks / Trade-offs

- 本地存储被禁用或损坏 → 明确提示，写失败不展示保存成功。
- 隐藏弹框与依赖残留 → 明確分层草稿和关闭策略，浏览器验证逐层取消。
- 本地练习规则被误当 MES 规格 → README 明确这是交互实验，不继承未确认的库存/称量语义。
- 文件不可跨刷新恢复内容 → 只保存文件名、大小和类型并明确标记。
- 不实现多标签页并发合并 → README 说明使用单标签页维护同一组示例数据。

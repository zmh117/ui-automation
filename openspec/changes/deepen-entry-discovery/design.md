## Context

用户已选择自动识别入口，范围包括新增、修改、详情、列表及展示功能按钮；主配方暂不探索。删除仅允许逐项明确配置为打开确认弹框，不能确认删除。现场结果中的位置定位、固定列按行号合并及忽略全部 URL 参数的判断不能直接引入。

## Goals / Non-Goals

**Goals:** 在现有可见性和唯一定位基础上自动探索，记录可重放路径与分支结果，支持同页、路由、iframe 和新窗口中的展示入口。

**Non-Goals:** 不生成业务规则、不填写表单、不确认或保存、不自动翻页穷尽数据，不扫描主配方，不执行现场生产脚本。

## Decisions

- 计划显式启用 `exploration`。有限队列按广度优先探索；每条分支重新进入场景并重放前置步骤及已验证路径，避免靠取消按钮或浏览器后退恢复草稿。
- 共享扫描器提供入口分类、拒绝原因和行上下文。按钮、链接、标签页、下拉、明确展示入口自动进入；未知按钮只记录。删除入口必须声明目标及预期确认弹框，弹框是探索终点。
- 原始单元格及控件继续作为事实来源，行操作引用同一控件，避免重复采集。只使用稳定行键及已有语义锚点，不合并固定列的第 N 行。
- 区分操作深度与 Frame/Shadow 深度；控制总动作数（包含重放）、快照数和等待期限。每次操作确认新界面或已关联弹层后再扫描；无变化、多个新弹框、不同来源、预算不足均明确报告。
- 页面路径保留完整 query/hash，不能把不同 ID 的编辑页面当成同一页面。只关闭本次打开的窗口，保留调用方原窗口。
- 默认排除入口名及页面标题/标题元素含“主配方”的范围，并支持增加排除名称和 URL 片段。缺少业务语义的路径需要配置；不宣称自动识别所有主配方路由。

## Risks / Trade-offs

- [按钮名称不能证明服务器无副作用] → 只允许有限展示语义；删除使用明确配置；真实部署先使用测试账号和受控环境，报告不宣称后端只读证明。
- [异步界面无法仅靠静态 DOM 保证稳定] → 在超时内等待可辨认变化及稳定窗口，超时记为未确认；业务特有状态后续专用规则。
- [动态数据导致重放不一致] → 每次重新解析唯一可见目标并核对已观察到的目标界面，失败即停止该分支。
- [部分现场图标没有语义] → 支持 title/aria-label 和明确的已知图标类；没有可靠定位仍标记 unresolved，不猜测业务字段。

## Context

现场包是独立副本，包含生产访问脚本、报告和临时修补代码。主要问题是序号隐藏在 combo/XPath 中，以及同一组件多层包装重复采集；不能直接覆盖主工程。

## Goals / Non-Goals

**Goals:** 控件无 ID 时用可验证语义/关系地址；稳定父子与兄弟锚点；同一控件每快照一条；失去区分依据则明确失败；生成和执行使用相同解析逻辑。

**Non-Goals:** 不推断业务规则、不自动登录真实生产、不导入现场凭证、不将相似文字自动匹配或无限遍历 DOM 当作可靠定位。

## Decisions

1. 地址继续用根内 selector 与 Shadow/Frame 链表达。CSS 适用于稳定属性；关系地址使用 `anchor=` 后的有限 JSON 步骤（后代、祖先、兄弟；CSS 类型过滤与精确文本/名称）。禁止索引和任意执行代码。无需 XPath，关系解析同样可在开放 Shadow 根运行。
2. 一个可序列化的浏览器函数同时提供扫描与根内解析，避免生成器和执行器语义分叉。步骤与候选有界；同一扫描用 WeakMap 缓存元素定位和规范组件，下一快照重新观察。
3. 稳定属性、关联 label/ARIA、静态标签/标题是锚点。无属性控件可沿父容器向上找锚点，或借助有唯一标签的子节点和兄弟节点。每个候选须回查仅命中目标；不以当前值、动态 ID、状态 class、截断文字或位置生成地址。
4. 已知 Element Plus/iView/md 组件归一到同一交互根，复选/单选装饰与内部 input 合并；不能按任意父子包含关系删除真实独立子控件。不同 Frame、Shadow、弹框和容器里的同名字段不合并；跨快照保留状态证据，草稿只合并同一身份。
5. 无可靠地址时 selector 为空、basis=unresolved，记录原因并使发现为 partial；草稿排除该字段，不能进入执行映射。只读单元格可保留无地址显示证据，不声称其可操作。
6. 版本升级到 3；原始报告留存，运行侧重建。以脱敏现场结构夹具和原实例真实浏览器回归验证；报告区分本地重现与真实环境验收。
7. 非 ID/testid 地址优先绑定最近且可唯一识别的命名区域；即使当前名称全局唯一，也不因后续出现同名弹框而改变原字段身份。分页等明确组件类型可作为父容器锚点，匿名 div 不作为锚点。
8. 既有执行脚本移除 nth/first：日期输入用开始/结束占位符，日历按月份按钮关联月份容器，清空按钮按所属输入反查组件。时间滚轮没有时/分/秒的区分语义，使用已命名输入框的键盘/输入及面板确认，不按列号点击。
9. CSS 与 anchor 地址在每步查询后都先过滤可见性，再判断唯一性；自身/祖先的 hidden、aria-hidden、inert、display:none、visibility:hidden/collapse、opacity:0 和 content-visibility:hidden 均排除。Shadow 沿宿主和 slot 追溯；Frame 由 Playwright 检查全部宿主入口。已隐藏的旧地址返回空，等待入口使用同一规则轮询，不提供隐藏元素绕过选项。可见但 disabled 的控件继续保留状态。

## Risks / Trade-offs

- 无可区分信息 → unresolved，要求补标识或组件适配，不按序号猜测。
- 标签内容会改版 → 旧地址解析不到时报告失败；不模糊更换目标。
- 匿名 Shadow 宿主或 Frame → 内部即使可读也不能伪造可重放入口。
- 复合控件错误合并 → 限定适配名单并覆盖真实子输入、隐藏内部 input 和同名双区域反例。
- 本地未覆盖生产私有组件 → 交付未定位清单与组件形状测试，保留现场复测边界。

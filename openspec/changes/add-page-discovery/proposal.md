## Why

全量枚举器已经独立实现，但字段模型需要手工提供。用户要求接入页面自动发现，并明确允许只读扫描及按指定入口打开下拉、标签页和弹框；输出待确认模型和报告，确认规则及取值后再枚举。

## What Changes

- 在现有包增加独立 `discovery` 入口，用 Playwright 读取真实 DOM 控件、标签、当前状态、DOM 约束及选项，不访问 Vue 私有实例。
- 增加有界入口计划，仅允许打开下拉、标签页和弹框，不切换业务单选/复选框、不保存、不注入数据。
- 生成发现报告、候选模型与确认模板；提供确认后的模型转换入口，接入现有全量枚举器。
- 以本项目 Vue 练习站作为主要验收对象，记录未探索、禁用入口、未知业务值及复杂控件边界。

## Capabilities

### New Capabilities
- `page-configuration-discovery`: 实时页面控件发现、受控入口观察、模型草稿与确认转换。

### Modified Capabilities

无；既有枚举 API 的行为保持一致。

## Impact

- 修改 `packages/config-enumerator`，增加 Playwright 可选运行依赖、发现/确认命令行、示例计划与测试。
- 不修改练习站业务规则或用户浏览器数据。
- 输出是观察证据与待确认配置，不将观察到的禁用、选项标签或 DOM 属性直接当作已批准业务规则。

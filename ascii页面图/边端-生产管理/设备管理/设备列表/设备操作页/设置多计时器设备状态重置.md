### 控件速查（给 agent 对齐字段）

| 区块 | 控件 | 类型/约束 | 当前样例状态 |
|------|------|-----------|--------------|
| 弹窗头 | 标题 | 「重置」 | 固定 |
| 页脚 | 取消 | 默认按钮 | **可点** |
| 页脚 | 确定 | primary | **可点** |
| 只读区 | 设备编码 | text **disabled** | 值未在 DOM `value` 露出 |
| 只读区 | 设备名称 | text **disabled** | 同上 |
| 只读区 | 设备参数 | text **disabled** | 同上（预期为状态参数名，如清洁状态） |
| 可选 | 设备状态 | 下拉；展示 input `readonly`；placeholder「请选择」 | **可打开**；本 DOM 未展开选项列表 |
| 只读区 | 剩余次数 | text **disabled** | 值未露出 |
| 只读区 | 报警时间 | prop=`alarm_time`；datepicker **disabled** | 不可改 |
| 勾选 | 重置次数 | checkbox **disabled** | ☐ 未勾且不可点 |
| 勾选 | 重置时限 | checkbox | **☑ 可点**（本态已勾） |
| 时限区 | 计时器选择 | 下拉；`readonly`；placeholder「请选择」；容器 `multi-timer-select` | **可打开**；本 DOM 未展开选项 |
| 时限区 | 开始时间 | prop=`start_time`；datepicker | **可编辑** |
| 时限区 | 到期时间 | prop=`end_time`；datepicker **disabled** | 不可手改（预期随开始时间/计时器效期计算） |

### 给 agent 的隐含关系（写用例时注意）

1. 入口：边端「生产管理 → 设备管理 → 设备列表」对某设备状态行做重置（具体入口按钮文案需列表页 DOM/需求确认）。
2. 本态 **重置次数** 禁用未勾、**重置时限** 已勾：可见「计时器选择 / 开始时间 / 到期时间」。取消「重置时限」后时限区是否隐藏，本 DOM 未覆盖。
3. 「重置次数」本态全程 disabled，勿写成可勾选项；何时可点需另贴 DOM 或结合需求。
4. **到期时间** disabled，写用例勿断言用户可直接改到期时间；与开始时间、所选计时器效期的联动需结合需求确认。
5. **设备状态**、**计时器选择** 下拉选项本段 DOM 未展开，勿臆造选项文案；计时器选项与云端多计时器配置（见设备分组清洁状态相关 ascii）可能相关，冲突以本页 DOM 为准。
6. 设备编码/名称/参数/剩余次数/报警时间均为回显只读；断言取值以界面可见或接口数据为准。
7. 页脚 **确定** 提交后列表状态/时限如何变化，DOM 仅见按钮可点，规则勿臆造。

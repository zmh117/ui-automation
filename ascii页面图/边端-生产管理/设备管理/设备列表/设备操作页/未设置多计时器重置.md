### 控件速查（给 agent 对齐字段）

| 区块 | 控件 | 类型/约束 | 当前样例状态 |
|------|------|-----------|--------------|
| 弹窗头 | 标题 | 「重置」 | 固定 |
| 页脚 | 取消 | 默认按钮 | **可点** |
| 页脚 | 确定 | primary | **可点** |
| 只读区 | 设备编码 | text **disabled** | 值未在 DOM `value` 露出 |
| 只读区 | 设备名称 | text **disabled** | 同上 |
| 只读区 | 设备参数 | text **disabled** | 同上 |
| 可选 | 设备状态 | 下拉；展示 input `readonly`；placeholder「请选择」 | **可打开**；选项未展开 |
| 只读区 | 剩余次数 | text **disabled** | 值未露出 |
| 只读区 | 报警时间 | prop=`alarm_time`；datepicker **disabled** | 不可改 |
| 勾选 | 重置次数 | checkbox **disabled** | ☐ 未勾且不可点 |
| 勾选 | 重置时限 | checkbox | **☑ 可点**（本态已勾） |
| 时限区 | 计时器选择 | — | **本态未渲染**（对比 `设备状态重置.md` 启用多计时器态有该下拉） |

| 时限区 | 到期时间 | prop=`end_time`；datepicker **disabled** | 不可手改 |

### 给 agent 的隐含关系（写用例时注意）

1. 入口同 `设备状态重置.md`：边端设备列表/操作页对某状态参数行做重置。本文件对应**未设置/未启用多计时器**时的重置弹窗快照。
2. 与 `设备状态重置.md`（启用多计时器）的关键差异：勾选「重置时限」后，本态 **不出现「计时器选择」**；仅见「开始时间 / 到期时间」。需求中「计时器选择灰色不可编辑」若产品实现为整项不渲染，以本 DOM 为准写断言（勿写「可见灰态下拉」除非另贴灰态 DOM）。
3. 「重置次数」本态 disabled 未勾；「重置时限」已勾且可点。取消「重置时限」后时限区是否隐藏，本 DOM 未覆盖。
4. **到期时间** disabled，勿断言可手改；未启用多计时器时到期时间按原【计时器支持】配置计算（规则见需求，本 DOM 仅见控件态）。
5. 设备状态选项、各只读回显值本段 DOM 未露出，勿臆造。
6. 页脚确定后操作页/列表到期时限如何变化，DOM 仅见按钮可点，结果断言结合需求与操作页 ascii。
7. 忽略页脚隐藏 `#myFocus`，不作用例控件。

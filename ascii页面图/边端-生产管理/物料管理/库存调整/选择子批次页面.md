1. 本页为库存调整流程的**步骤1**（非整页弹窗）：页头展示「步骤1：选择子批次 >> 步骤2：确定调整」；**扫码** 本 DOM 为 `disabled`；**下一步 (F12)** 为 primary——未勾选/已勾选时能否进入步骤2、扫码何时启用、F12 是否等价点击，DOM 仅表现当前态，需结合需求确认。
2. 相对「库存盘点 / 选择子批次」：本页查询多 **质量状态**，**物料编码** 本态隐藏（盘点页可见）；列表有 **物料规格 / 数量 / 质量状态 / 操作(详情)**，无 **系统库存 / 盘点存货量 / 备注**；页头下一步文案带 `(F12)`，步骤旁注为「确定调整」而非盘点后续步骤。写用例勿混用两套字段。
3. 相对「出库管理 / 选择子批次」弹窗：本页为步骤页（扫码/下一步），非取消/确定弹窗；查询可见 **物料名称**；列表有 **序号 / 物料规格 / 操作**，无 **包装规格 / 状态**。写用例勿混用。

### 给 agent 的隐含关系（写用例时注意）

1. **形态是弹窗，不是步骤页**。页脚为 **取消 / 确定**，非移库寄库等「扫码 / 下一步 (F12)」。来源：`returnAdd.vue` 的 `MdModal` + `showModal`。
2. **入口**：退料申请页「子批次号」输入旁的 **选择** 打开本弹窗；同区还有手工输入+确认添加、扫码——写用例时区分「弹窗勾选」与「输入校验添加」两条路径（手工路径校验在 `validateSub`，勿混为弹窗内校验）。
3. **查询区极简**：可见查询项**仅「物料名称」**（纯文本，placeholder「请输入」）；展开/折叠 `display:none`。筛选用例勿抄出库/盘点/移库的子批次号/批次号/质量状态/位置等字段。
4. **列表数据过滤（接口侧，写前置/负向必测）**：`api_sublot_query` 固定带  
   - `page_type: 3`（注释：查未被使用的子批次，并过滤数量为 0）；  
   - `allocate: [未分配/undistributed]`；  
   - `org_code: returnInfo.org_code`；  
   - `mat_name_like_flag: 1`。  
   故列表预期**不应出现**已分配/数量为 0/非本 org 等数据（以接口实现为准）。
5. **多选与跨页**：勾选写入 `selectLists`；翻页后仍保留；打开弹窗时用主表 `tableData` 初始化 `selectLists`，当前页已选项打 `_checked`。**确定**用整份 `selectLists` **整表覆盖**主表（取消勾选后确定会从主表移除）。**取消**不写回。是否允许 0 条确定写回空表：代码未拦，需结合需求确认。本 DOM 样例 8 行均未勾选。
6. **列（以页面为准）**：物料名称 → 规格 → 编码 → 批次号 → 数量 → 状态 → 工单号 → 物料类型 → 质量状态 → 子批次号 → **生产使用批号** → 存储位置；本样例无放行状态、无序号/源位置/操作列。相对移库寄库步骤页字段差异大，勿混用。
7. 「状态」=`allocate`（分配态，样例「未分配」）与「质量状态」=`quality_status`（badge「合格」）为独立列，写断言勿混。批号类列：**批次号 / 子批次号 / 生产使用批号**（可为空）亦勿混用。
8. **放行状态列**随 `isOpenRelease` 显隐；本 DOM 未出现，对应用例按「关风险放行」分支；开启时该列插在质量状态与子批次号之间（代码顺序）。
9. 物料名称/编码/类型部分单元格带绿色样式（`rgb(0,175,80)`）；代码按 `quality_status` 上色，语义勿臆造业务规则。
10. 空态 tip 文案为「暂无筛选结果」；本样例有数据故 tip 隐藏——筛选无结果时 tip 是否出现需结合操作确认。

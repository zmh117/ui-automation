### 给 agent 的隐含关系（写用例时注意）

1. **形态是弹窗，不是步骤页**。相对「库存调整 / 移库寄库 / 拆分子批次」的「步骤1：选择子批次」（扫码 / 下一步 F12），本页为退料申请（`returnAdd`）上的 **取消 / 确定** 弹窗；相对「出库管理 / 选择子批次」同为弹窗，但**查询与列差异大**，勿混用。
2. **入口**：退料申请页「子批次号」输入旁的 **选择** 打开本弹窗；同区还有手工输入+确认添加、扫码（PC 站 `isPc` 时扫码 disabled）——写用例时区分「弹窗勾选」与「输入校验添加」两条路径。
3. **查询区极简**：代码 `searchParams` **仅物料名称**一项；无出库弹窗的子批次号/批次号/质量状态/位置/物料编码，也无展开折叠隐藏项。筛选用例勿抄出库/盘点字段。
4. **列表数据过滤（接口侧，写前置/负向必测）**：`api_sublot_query` 固定带  
   - `page_type: 3`（注释：查未被使用的子批次，并过滤数量为 0）；  
   - `allocate: [未分配/undistributed]`；  
   - `org_code: returnInfo.org_code`（与申请页 ERP 组织联动）；  
   - `mat_name_like_flag: 1`。  
   故列表预期**不应出现**已分配/数量为 0/非本 org 等数据（以接口实现为准，断言前结合环境确认）。
5. **多选与跨页**：勾选写入 `selectLists`；翻页后仍保留；打开弹窗时用主表 `tableData` 初始化 `selectLists`，当前页已选项打 `_checked`。**确定**用整份 `selectLists` **整表覆盖**主表（取消勾选后确定会从主表移除）。**取消**不写回。是否允许 0 条确定写回空表：代码未拦，需结合需求确认。
6. **列差异（相对出库选择子批次）**：本表有 **物料规格 / 工单(wo) / 放行状态(条件)**，有 **状态(allocate)**；**无** 包装规格、生产批号、生产使用批号、序号、操作列。列顺序为：物料名称 → 规格 → 编码 → 批次号 → 数量 → 状态 → 工单 → 物料类型 → 质量状态 →（放行）→ 子批次号 → 存储位置。
7. **质量状态 vs 状态**：列表「状态」=`allocate`（分配态），「质量状态」=`quality_status`（标签）；写断言勿混。代码里质量状态**展示文案**用 `BATCH_EXPIRY_STATUS` 枚举，若界面与「合格/待检」等预期不符，先对照实现再写死断言。
8. **放行状态列**随设置开关显隐（`updateRelaseView` / `isOpenRelease`）；关风险放行时表头无该列——用例需按环境配置分支。
9. **物料名称/编码/类型**单元格可按质量状态着色；语义需结合需求，勿臆造。
10. 本页无 DOM 样例行与空态 tip 文案；空表 tip、默认每页条数以运行界面为准。主表侧手工输入添加另有「非未分配 / 数量为 0 / 重复子批次」等校验（`validateSub`），与弹窗勾选路径不同，写用例勿混为弹窗内校验。

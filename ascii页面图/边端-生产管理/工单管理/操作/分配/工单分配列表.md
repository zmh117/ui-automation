### 给 agent 的隐含关系（写用例时注意）

1. 本页为工单列表进入的**分配子页**（`work-alloc`），顶部 **返回** 为主按钮，通常回到工单列表；**库存查询 / 快速领料** 入口本 DOM 未展开后续弹窗/页，需另抓。
2. **工单信息** 与 **物料组成汇总**（所需量/合计分配量/不足量）字段均为 **disabled 只读**，值应由进入页时回填；本 DOM 输入 value 未出现在 HTML 中，断言时勿当成「业务空值」除非界面确认空白。
3. 页内同时存在 **批次号** 与 **生产批号** 两个独立只读字段，写用例/断言勿混用。
4. **分配** 为下拉按钮（含「删除」项）；本样例整钮 `md-button-dropdown-disabled`，下拉项亦 disabled。何时可点（如选中物料行后）需结合交互确认，勿臆造启用条件。
5. 物料表空字段占位多为 `/`；「固定」「允许多批次投料」为是/否文案；数量带单位（样例 `km`）；误差单位样例为 `%`。
6. 行操作仅见删除 icon，且本样例 `icon-disabled` + tooltip 隐藏；与汇总区「分配▾→删除」是否同一能力、何时启用，需结合需求/更多状态样例确认。
7. 分页共 1 条；空表时有「暂无筛选结果」tip（本样例有数据，tip `display:none`）。
8. 本 DOM **不含** 库存查询/快速领料/分配弹窗内容；相关页面需另补 ASCII。

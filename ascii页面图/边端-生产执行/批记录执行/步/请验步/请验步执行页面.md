### 给 agent 的隐含关系（写用例时注意）

1. 顶栏主操作为 **请验确认**（本 DOM 无「返回」按钮，与投料报告步不同）。点击后是否调 LIMS、是否写接口日志，需结合需求确认；本页 DOM **无**「组织编码/组织代码」字段展示。
2. **产品代码 / 产品名称 / 产品规格** 为 disabled，通常由工单/物料回填；**请验单号、批次号、取样数量、请验部门、检验类别、是否加急、留样数** 等为必填可编（或下拉）。
3. **取样数量、批次数量** 均为「数值 + 单位下拉」组合；单位下拉选项极长（含测试脏数据如超长中文、`xxx`、`2233` 等），写用例断言时勿把整表选项当业务枚举，按实际选中值断言即可。
4. **样品分类 / 检验类型 / 检验类别 / 是否加急** 的下拉选项在本 DOM 中**未展开**（无 `md-down-ul` 项），写具体选项用例需另抓展开态 DOM。
5. 页脚 **打印** 本样例 **disabled**；与「请验确认」是否成功、份数是否填写的关系 DOM 未体现，需结合需求确认。
6. 标题区收起 icon 为 `icon_shouqi`；折叠后表单区是否仍可操作，本 DOM 未展示折叠后态。
7. 本页触发请验成功后，核对 LIMS 报文 `organizationcode` 应走 **日志管理 → 详细数据 → 发送数据**，取值源在工单详细「组织代码」，**不在本请验表单**。

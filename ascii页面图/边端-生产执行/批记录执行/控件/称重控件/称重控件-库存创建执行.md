### 给 agent 的隐含关系（写用例时注意）

1. **入口**：边端称重控件执行 → 确认净重后弹出；前置配置须勾选【称重创建批次】（配置页见同目录 `称重控件` 配置 ASCII / 云端主配方称重控件）。本 DOM 仅为弹窗，不含称重主界面步骤。
2. **与库存创建控件「增加库存创建批次」差异（以本 DOM 为准）**：本弹窗有【子批次号】、数量文案为【称量数量】；**无**精度/物料规格/包装规格/含量/含水量/干燥失重/容器/「添加到报工」；物料代码旁**无**【选择】（整段物料/批次/数量多为称重回填且 disabled）。
3. **必填（DOM `ivu-form-item-required`）**：批次号、子批次号、称量数量、生产日期、有效期、存储位置。物料名称/物料代码/生产批号/质量状态/车间子库无必填类。
4. **可编辑/可点**：质量状态（下拉）、生产日期、有效期、存储位置【选择】、车间子库【选择】、页脚【取消】【确定】。其余样例字段为 disabled 展示。
5. 【车间子库】下拉本身 disabled，选项样例含 `2` / `ERP库位` / `描述描述`；赋值靠旁侧【选择】。写「未配置过滤关系须选车间子库」类用例时，断言点【确定】后的提示与拦截，勿把下拉直接可点写进步骤。
6. 页脚【确定】提交库存创建；【取消】关闭。隐藏 `#myFocus` 忽略。

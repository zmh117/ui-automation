### 给 agent 的隐含关系（写用例时注意）

1. 入口：步骤1 选工单后【下一步】进入本页；【上一步】回选工单；【报工】为提交主操作（成功/拦截提示本 DOM 未见）。
2. Tab 右侧【新增】与当前 Tab 同栏；点【新增】打开的弹窗本 DOM 未包含，需另抓。写「投料新增」用例勿臆造弹窗字段。
3. **数据来源（用户补充）**：工序记录中执行【物料使用】、【物料损耗】控件消耗的物料，会进入本【投料】表。写「投料报工物料过滤 / 报工接口不发 ERP」类用例时，先确认过滤列表物料经物料使用/物料损耗执行后，在本表能查到对应**物料代码**行，再点【报工】核对 ERP 侧是否过滤。
4. 投料表呈 **母行 + 明细行**：母行带物料名称/步骤编号/步骤次序，数量等多为 `/`，操作多为 `/`；明细行物料名称/步骤为空，带规格、数量、批次、投料量、状态「已投」及操作 `md-more`。断言过滤物料是否出现在列表时，以**物料代码列**及明细行为准。
5. 操作列固定右侧；`md-more` 为 hover 下拉，**菜单项文案本 DOM 未展开**，勿编造编辑/删除项。
6. 投料分页固定 pagesize=15、无条/页切换；产出/工时/损耗本 DOM 未展示分页控件（产出仅见表）。
7. 本文件聚焦【投料】Tab；产出/工时/损耗仅列头备查。若要写其它 Tab 用例，建议另抓 active 态 DOM 补独立 ASCII。

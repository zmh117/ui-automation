### 控件速查（给 agent 对齐字段）

| 区块 | 控件 | 类型/约束 | 当前样例状态 |
|------|------|-----------|--------------|
| 弹窗头 | 标题 | 「配置参数」 | 固定 |
| 页脚 | 取消 | 默认按钮 | **可点** |
| 页脚 | 确定 | primary | **可点** |
| 基础信息 | 参数编码 | prop=`code`；text **disabled** | 值未在 DOM `value` 露出；入口行预期为 `CLEAN_STATUS` |
| 基础信息 | 类型 | 下拉；展示 **disabled+readonly**；placeholder「请选择」 | 本态不可改；选项：文本/数值/列表/状态 |
| 基础信息 | 描述 | text **disabled** | 值未露出；入口行预期为「清洁状态」 |
| 基础信息 | 常量 | checkbox；true=1/false=0；**disabled** | ☐ 未勾 |
| 参数配置 | 整块 | `display:none` | **本态不可见** |
| 参数配置（隐藏） | 长度范围(1-250) | text disabled | 隐藏区内 |
| 参数配置（隐藏） | 默认值 | textarea rows=4；prop=`defaultText` | 隐藏区内；可编辑 textarea 本体无 disabled |
| 状态信息配置 | 表列 | 序号/状态名/同步改值/计数器/计时器/默认项/操作 | 3 行样例；表 max-height≈180 |
| 状态信息 | 行1 | 未清洁 | 同步改值=是（`color-red`）；计数器=否；计时器=否；默认项=是；改/处理可 |
| 状态信息 | 行2 | 已清洁 | 同步改值=是（红）；计数器=否；计时器=0天；默认项=否；改/处理可 |
| 状态信息 | 行3 | 已消毒 | 同步改值=是（红）；计数器=否；计时器=0天；默认项=否；改/处理可 |
| 状态转换配置 | 表列 | 序号/状态起点/状态终点/转换事件/操作 | 6 行样例 |
| 状态转换 | 行1～6 | 见 ASCII | 操作仅 **详情** `icon_xiangqing` |

### 给 agent 的隐含关系（写用例时注意）

1. 入口：设备分组「参数」表对 **CLEAN_STATUS**（或同类状态参数）点 **详情/修改** → 打开本弹窗「配置参数」；父页见 `新建修改详情设备分组.md`。
2. 本态基础信息（编码/类型/描述/常量）均为 **disabled**，不可在弹窗内改编码与类型；可见编辑焦点在 **状态信息配置 / 状态转换配置**。
3. 「参数配置」整块 `display:none`：当前类型表现为状态机态，文本类「长度范围/默认值」不展示；勿把隐藏区字段写成必填可见项。
4. **状态信息** 默认项仅「未清洁」=是；三行「同步改值」均为是且带红色样式。
5. **状态转换** 含「操作步骤」「计时器超时」两类事件；同一起终点可有多条（如已清洁→未清洁 既有操作步骤又有计时器超时）。
6. 状态行操作是 **修改 + 处理**（非删除）；转换行操作是 **详情**。处理/修改/详情子页结构需另贴 DOM。
7. 页脚 **确定/取消** 是否写回父表参数默认值（如默认「未清洁」），DOM 仅见按钮可点，写回规则需结合需求确认。

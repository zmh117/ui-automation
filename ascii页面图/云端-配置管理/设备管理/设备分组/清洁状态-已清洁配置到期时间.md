### 控件速查（给 agent 对齐字段）

| 区块 | 控件 | 类型/约束 | 当前样例状态 |

### 给 agent 的隐含关系（写用例时注意）

1. 入口：`清洁状态配置页.md` → 状态信息配置表「已清洁」行 **修改**（`icon_xiugai`）→ 本弹窗「状态配置」。文件名含「配置到期时间」，对应本态已启用计时器 + 多计时器列表中的效期/临界值。
2. 本态大量开关/数值为 **disabled**（状态名、启用列表同步改值、启用计数器、启用计时器及两侧 number/单位下拉）；**仍可点**的主要是：列表同步「选择」、启用多计时器、多计时器「添加」、行内修改/删除、页脚取消/确定。
3. 「启用计数器支持」未勾且相关 number 为 disabled；「启用计时器支持」已勾但单计时器效期/临界值控件仍 disabled——效期展示以多计时器列表为准（样例 1 天），勿断言单字段可手改。
4. 「启用多计时器」可勾选；已勾时展示「多计时器列表」+「添加」。取消勾选后列表是否隐藏，本 DOM 未覆盖，需另贴态。
5. 多计时器行「默认=是」时，处理 icon 为 disabled；修改/删除可点。添加/修改子页结构需另贴 DOM。
6. 列表同步改值旁「选择」可点，打开选择弹窗写回规则需结合需求/后续 DOM；输入框本身 disabled。
7. 页脚确定是否写回父表「计时器」列（如 0天→1天），DOM 仅见按钮，规则勿臆造。

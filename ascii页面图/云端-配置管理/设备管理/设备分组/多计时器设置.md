根据你贴的页面 DOM，多计时器列表点**添加**（或行内修改）打开的 **【多计时器设置】** 弹窗结构可抽象为下面这张 ASCII 示意（给后续 agent 写用例用）：

```
┌─【弹窗】多计时器设置 ──────────────────────────────────────────────┐
│  多计时器设置                                                      │
├────────────────────────────────────────────────────────────────────┤
│  计时器名称 * (prop=name)                                          │
│  [文本输入 maxlength=20]                                           │
│                                                                    │
│  计时器效期 * (prop=time)                                          │
│  [number min=0 max=999999999 precision=0]  [下拉 请选择](单位)     │
│                                                                    │
│  临界值时间 (prop=time_warn)                                       │
│  [number min=0 max=999999999 precision=0]  [下拉 请选择](单位)     │
├────────────────────────────────────────────────────────────────────┤
│                                      [ 取消 ]  [ 确定 ](primary)   │
└────────────────────────────────────────────────────────────────────┘
```

### 控件速查（给 agent 对齐字段）

| 区块 | 控件 | 类型/约束 | 当前样例状态 |
|------|------|-----------|--------------|
| 弹窗头 | 标题 | 「多计时器设置」 | 固定 |
| 页脚 | 取消 | 默认按钮 | **可点** |
| 页脚 | 确定 | primary | **可点** |
| 表单 | 计时器名称 | prop=`name`；**必填**；text；maxlength=**20** | 空 |
| 表单 | 计时器效期 | prop=`time`；**必填**；number；min=0；max=999999999；precision=0 | 空；旁单位下拉 placeholder「请选择」 |
| 表单 | 计时器效期·单位 | md-select；readonly 触发；placeholder「请选择」 | 未选 |
| 表单 | 临界值时间 | prop=`time_warn`；**非必填**；number；min=0；max=999999999；precision=0 | 空 |
| 表单 | 临界值时间·单位 | md-select；readonly 触发；placeholder「请选择」 | 未选 |

### 给 agent 的隐含关系（写用例时注意）

1. 入口：`清洁状态-已清洁配置到期时间.md`（状态配置）→ 勾选「启用多计时器」后多计时器列表 **添加** / 行内 **修改** → 本弹窗。
2. 必填仅两项：`计时器名称`、`计时器效期`（DOM 带 `ivu-form-item-required`）；`临界值时间` 无必填标记。
3. 名称上限 **20** 字（`maxlength=20`）；效期/临界值 number 同为 min=0、max=999999999、precision=0（整数）。
4. 效期、临界值均为「数值 + 单位下拉」并排；单位下拉 placeholder 均为「请选择」，本 DOM 未展开选项列表（天/时等勿臆造）。
5. 页脚「确定」预期写回父弹窗多计时器列表；「取消」关闭不保存——写回列与校验失败提示原文需结合需求/另贴态，本 DOM 未见错误提示。
6. 忽略页脚隐藏 `#myFocus` 输入，不画入 ASCII、不作用例控件。

根据你贴的页面 DOM，「云端-配置管理 / 主配方设置 / OPC通讯步」弹窗「配置」（开始采集 / 结束采集共用）结构可抽象为下面这张 ASCII 示意（给后续 agent 写用例用）。

本文档含两份样例（同一弹窗标题「配置」）：
- **样例 A**：单选 **链接**（`ivu-radio-wrapper-checked`）→「绑定点位号」可点；「变量」行 disabled；「节点全名」可编
- **样例 B**：单选 **信号量** →「变量」可点；「绑定点位号」行 disabled；「节点全名」disabled

由主配置页「开始采集」「结束采集」旁【配置】打开（见 `配置项.md`）。


### 控件速查（给 agent 对齐字段）

| 区块 | 控件 | 类型/约束 | 样例 A（链接） | 样例 B（信号量） |
|------|------|-----------|----------------|------------------|
| 弹窗 | 标题 | 「配置」`md-modal-header-title` | 同左 | 同左 |
| 表单 | 触发信号 | 文本；maxlength=64 | 空；可编 | 空；可编 |
| 单选组 | 信号量 | radio | 未选 | **已选 checked** |
| 信号量行 | 变量值 | 只读文本 | **disabled** | 只读可展示（未 disabled） |
| 信号量行 | 变量 | 主按钮 | **disabled** | **可点** |
| 单选组 | 链接 | radio | **已选 checked** | 未选 |
| 链接行 | 点位值 | 只读文本 | 只读可展示 | **disabled** |
| 链接行 | 绑定点位号 | 主按钮 | **可点** | **disabled** |
| 标签 | 节点全名 | `trigger-input-label` | 可见 | 可见 |
| 表单 | 节点全名 | 文本；maxlength=256 | **可编** | **disabled** |
| 页脚 | 取消 | 默认按钮 | 可点 | 可点 |
| 页脚 | 确定 | 主按钮 | 可点 | 可点 |

### 给 agent 的隐含关系（写用例时注意）

1. 单选 **信号量 / 链接** 互斥，切换后对侧「变量 / 绑定点位号」与「节点全名」启用态联动（见样例 A/B）。
2. 「变量」「绑定点位号」打开的下级选择弹窗本 DOM **未包含**；确定后应写回对应只读框，再由本弹窗「确定」写回主配置「开始采集 / 结束采集」只读框。
3. 「触发信号」两样例均可编辑（maxlength=64）；与单选模式的必填/校验关系 DOM 未写明，需结合需求确认。
4. 「节点全名」仅在 **链接** 模式下可编；信号量模式下 disabled——写用例勿在信号量态断言可改节点全名。
5. 开始采集与结束采集共用本「配置」弹窗结构；写步骤时用主页按钮文案区分入口。

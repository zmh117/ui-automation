### 控件速查（给 agent 对齐字段）

| 区块 | 控件 | 类型/约束 | 当前样例状态 |
|------|------|-----------|--------------|
| 表单 | 物料编码 | 必填（required）；prop=`matCode`；输入 disabled；旁「选择」 | 输入空；选择可点 |
| 表单 | 物料名称 | 必填（required）；prop=`matName`；输入 disabled | 输入空；无旁侧按钮 |
| 表单 | 称量范围下限 | number；带 append 单位 | 空 |
| 表单 | 称量范围上限 | number；带 append 单位；与下限用 `-` 分隔 | 空 |
| 页脚 | 取消 | 默认按钮 | 可点 |
| 页脚 | 确定 | 主按钮 | 可点 |

### 给 agent 的隐含关系（写用例时注意）

1. **物料编码 / 物料名称** 均不可手输（disabled），依赖「选择」带出；名称无独立选择按钮，通常随编码一并回填。
2. **物料编码、物料名称** 带 `ivu-form-item-required`，提交前应有必填校验。
3. **称量范围** 为区间：下限 `-` 上限，两框均为 `type=number`；单位在输入框 append 区（当前 DOM 单位文案为空，可能随物料/系统单位动态带出）。
4. 页脚 **取消** 关闭不保存；**确定** 校验通过后写回主配置页「称量范围」表格。

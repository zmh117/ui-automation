### 控件速查（给 agent 对齐字段）

| 区块 | 控件 | 类型/约束 | 当前样例状态 |
|------|------|-----------|--------------|
| 基础信息 | 描述 | 文本，max 64；旁有「选择」 | 输入空；选择 disabled |
| 基础信息 | 使用变量 | checkbox | 未勾选 |
| 称量范围 | 添加 | 按钮 | 可点 |
| 称量范围 | 物料表 | 编码/名称/范围/操作 | 1 行：A / A / `1 km - 2 km` |
| 称量范围 | 行操作 | 修改、删除 | 有 |
| 称量范围 | 签名确认开关 | checkbox（true=1/false=0） | **已勾选** |
| 称量范围 | 签名确认值 | 只读输入 + 清空；旁「变量」 | 空 |
| 执行范围 | 访问权限 | 只读输入；旁「选择」 | 空 |
| 执行范围 | 强制分页 | checkbox（true=1/false=0） | 未勾选 |

### 给 agent 的隐含关系（写用例时注意）

1. **「使用变量」** 与描述区「选择」联动：未勾选时「选择」常为 disabled（与当前 DOM 一致）。
2. **「签名确认」开关** 控制签名确认输入/「变量」是否生效；当前为勾选态。
3. **称量范围** 是可增删改的表格配置，不是单字段。
4. **访问权限**、**签名确认值** 均为选择/变量注入型只读展示，不是手输。

### 控件速查（给 agent 对齐字段）

| 区块 | 控件 | 类型/约束 | 当前样例状态 |
|------|------|-----------|--------------|
| 弹窗头 | 标题 | 「添加参数」 | 固定（修改态标题是否变为「修改参数」需另贴 DOM） |
| 页脚 | 取消 | 默认按钮 | **可点** |
| 页脚 | 确定 | primary | **可点** |
| 基础 | 参数类型 | 下拉；readonly 展示；placeholder「请选择」 | 可打开；本 DOM 选项仅见「状态」 |
| 基础 | 参数编码 | text **disabled** +「参数」primary | 输入空；**参数可点**（打开选参） |
| 取值 | 单选 1 / 2 | radio group | **1** 已选（参数固定值） |
| 取值 | 参数固定值 | 下拉；readonly；placeholder「请选择」 | 可打开；选项：未清洁/已清洁/已消毒 |
| 取值 | 参数变量 | text **disabled** +「变量」**disabled** | 本态因选固定值而禁用 |
| 返回值 | 勾选 | checkbox（无独立 true-value 文案旁） | ☐ 未勾 |
| 返回值 | 输入+变量 | disabled 输入 +「变量」disabled | 未勾返回值时不可用 |
| 有效时间 | 勾选 | checkbox；true=1/false=0 | **☑ 已勾** |
| 有效时间子项 | 有效期限 / 增加时限 / 重置时限 | radio group | **重置时限**已选 |
| 有效期限 | 输入+变量 | disabled + 变量 disabled | 本态未选该子项 |
| 增加时限 | 输入+单位下拉+变量 | 均 **disabled** | 本态未选该子项；单位下拉 placeholder「请选择」 |
| 重置时限 | 计时器选择 | readonly+clearable 输入 +「变量」primary + `icon_yiwen` 帮助 | 输入可清；变量 **可点** |

### 给 agent 的隐含关系（写用例时注意）

1. 入口：`设备参数修改控件.md` →「参数（状态机）」**【添加】** → 本弹窗；确定后写回状态机表（编码/值/返回值/有效时间/类型/数据）。
2. **参数类型** 本 DOM 下拉仅展开到「状态」一项；是否还有其他类型取决于入口（状态机添加 vs 数值文本添加），勿臆造。
3. **参数编码** 不可手输，靠旁路【参数】选择回填（与父表 `CLEAN_STATUS` 一类编码对应）。
4. 取值互斥：选「1 参数固定值」时变量行 disabled；选「2 参数变量」时期望固定值下拉禁用（本 DOM 未切到该态，需另贴确认）。
5. **返回值** 未勾 → 输入与变量 disabled；勾选后是否启用需另贴。
6. **有效时间** 已勾才展开三种子方式：有效期限 / 增加时限 / **重置时限**。父表样例「类型=重置时限、数据=@计时器1@」对应本态计时器选择+变量。
7. 未选中的有效时间子项控件均为 disabled；写用例勿断言可同时编辑三种时限。
8. 文件名含「添加修改」；本 DOM 标题为「添加参数」。修改态字段可编辑性差异需另贴 DOM 再断言。
9. 计时器选择旁帮助 `icon_yiwen` 文案本 DOM 未展开 tooltip，勿臆造帮助原文。

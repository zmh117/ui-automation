根据需求规格书截图（docx 内 image3，图2「配置」添加查询属性），添加/修改单条查询属性弹窗结构可抽象为下面这张 ASCII 示意（给后续 agent 写用例用）：

```
┌─【弹窗】配置 ──────────────────────────────────────────────────────────────┐
│                                                                            │
│  查询内容                                                                  │
│  ┌──────────────────────────────────────────────────────────────────────┐ │
│  │ 物料批次号                                              ▾            │ │
│  └──────────────────────────────────────────────────────────────────────┘ │
│                                                                            │
│  输出结果                                                                  │
│  ┌─────────────────────────────────┐  [ 变量 ]  [ 清空 ]                  │
│  │ [只读/灰显文本]                 │                                      │
│  └─────────────────────────────────┘                                      │
│                                                                            │
│                              [ 取消 ](描边)    [ 确定 ](primary)           │
└────────────────────────────────────────────────────────────────────────────┘
```

### 控件速查

| 区块 | 控件 | 类型/约束 | 当前样例状态 |
|------|------|-----------|--------------|
| 标题 | 配置 | 弹窗标题 | 可见 |
| 表单 | 查询内容 | 下拉 | 样例选中「物料批次号」 |
| 表单 | 输出结果 | 只读展示框 +【变量】【清空】 | 靠【变量】绑定；【清空】清空绑定 |
| 页脚 | 取消 / 确定 | 按钮 | 可点 |

### 隐含关系

1. 由查询项配置页【添加】（修改时同结构）打开；确定后写回查询项列表。
2. 需求可选查询内容：物料批次号、物料子批次号、生产批号、计量单位、包装规格、批次有效期、生产日期、物料规格、物料编码、库存量、物料名称、化验单号、干燥失重、供应商、供应商批次、含量、含水量。
3. 输出结果变量类型须与查询内容匹配（文本 / 时间日期 / 数值，见需求对照表）。
4. 本文件来源为需求截图，非现场 DOM；若与最新 DOM 冲突以 DOM 为准。

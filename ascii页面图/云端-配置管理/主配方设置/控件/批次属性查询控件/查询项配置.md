### 控件速查

| 区块 | 控件 | 类型/约束 | 当前样例状态 |
|------|------|-----------|--------------|
| 标题 | 配置 | 弹窗标题 | 可见 |
| 工具栏 | 添加 | 描边按钮 | 可点；打开添加查询属性弹窗 |
| 表 | 查询内容 | 文本 | 样例：物料子批次号、剩余量 |
| 表 | 变量 | `@变量名@` | 样例：`@测试变量@`、`@测试@` |
| 表 | 默认 | 勾选标记 | 第 1 行有 ✓ |
| 表 | 操作 ⋮ | 菜单 | **修改** / **删除** / **默认** |
| 页脚 | 取消 / 确定 | 按钮 | 可点 |

### 隐含关系

1. 由清单行操作【配置】进入本弹窗；【添加】打开「添加查询属性」子弹窗（见同目录 `添加查询属性.md`）。
2. 【修改】改查询属性与绑定变量；【删除】删一行；【默认】将该查询属性设为默认，并用于工序记录单元格默认显示。
3. 需求：最多绑定 15 个查询属性；【重置】在上层清单操作中，清空全部查询项。
4. 截图查询内容出现「剩余量」；需求可选列表写「库存量」——写断言时查询内容枚举以需求列表为准，截图「剩余量」作样例行参考，冲突需再确认。
5. 本文件来源为需求截图，非现场 DOM；若与最新 DOM 冲突以 DOM 为准。
